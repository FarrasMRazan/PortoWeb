# Farras Muhammad Razan — Game Developer Portfolio

This repository contains the single-file portfolio website for Game Developer Intern applications.

## Contents
- `index.html` — responsive portfolio website. The Spora title-screen and gameplay images are embedded in the HTML, so no separate asset folder is needed.

## Enable GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Open the **Actions** tab and wait for the workflow named **Deploy portfolio to GitHub Pages** to finish.
4. When deployment succeeds, GitHub will show the public website URL in **Settings → Pages**.

## Repository visibility
This repository is currently private. For a publicly accessible portfolio on a GitHub Free account, change visibility to **Public** under **Settings → General → Danger Zone → Change repository visibility** before enabling Pages. Do not change this if you intentionally need to keep the source private and your GitHub plan supports private Pages.
